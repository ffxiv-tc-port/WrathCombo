# Wrath Combo

[WrathCombo](https://github.com/PunishXIV/WrathCombo) 的台服移植版。把連擊與互斥技能整合到單一按鍵上的職業循環插件，PvE、PvP 皆可用。

## 功能

**PvE**
- 多數職業提供「簡易」（單鍵）模式與可自訂複雜度的「高級」模式
- 自動循環：依設定自動執行完整輸出／治療循環，AoE 所需目標數可逐職業設定
- 多變迷宮專用功能；博茲雅與新月島的專屬技能（新月島輔助職業技能可加入循環）
- 坦克雙重仇恨保護、坦克打斷；治療職業自動復活；
  魔法遠程雙重昏亂保護與復活；近戰雙重牽制與真北保護；
  物理遠程雙重減傷保護與打斷

**PvP**
- 各職業「爆發模式」攻擊、緊急治療、緊急防護、快速淨化、防護取消預防
- 全職業開關：目標不是玩家時不放控場技能、目標不是玩家時不放長冷卻技能、目標太近時不放位移技能（三項預設關）

**其他**
- 無人島衝刺
- 園藝／採礦：優雷卡、定位與真相
- 捕魚：拋竿到上鉤、潛水

## 與其他插件整合

- **Orbwalker**：自動循環模式下選擇施法時自動停下移動，不需手動停止
- **[AutoDuty](https://github.com/ffxiv-tc-port/AutoDuty)**：可作為副本自動戰鬥引擎
- **[BossMod Reborn](https://github.com/ffxiv-tc-port/BossmodReborn)**：見下方「搭配 BossMod Reborn」
- **[DailyDuty](https://github.com/ffxiv-tc-port/DailyDuty)**：DailyDuty 的通緝令「自動開打」提出要求時，自動循環可以在戰鬥外對它指定的那一隻通緝目標出招（設定「DailyDuty 通緝目標繞過『僅於戰鬥中』限制」，預設開）。只在 DailyDuty 提出要求、而且你目前的目標正是那一隻時才作用；要求最多維持 10 秒，進入戰鬥或 DailyDuty 停下就結束。沒裝 DailyDuty 或它那一項沒開時，這個設定沒有任何作用
- **[MonsterDex](https://github.com/ffxiv-tc-port/MonsterDex)**：可設定略過確定免疫眩暈的敵人（預設關；查不到資料一律當作可以眩暈）

AutoDuty 啟用時，會自動鎖定必要的連擊設定為「開啟」以確保循環能運作。

### 搭配 BossMod Reborn

有裝 BossMod Reborn 時，自動循環會參考它對首領機制的判斷。它沒載入、版本太舊或沒有資料時，下列各項都退回原本的行為；你自己按的技能一律不擋。

- **位移技落點**：放位移技前先問落點安不安全，危險就改用別的技能
- **停手機制期間暫停出招**（預設開）：熱病、加速度炸彈這類「出任何招都會出事」的機制，從生效前 1 秒起到解除為止不出招，解除後自動恢復；單次暫停超過 30 秒視為異常，自動恢復出招
- **照危險讀條標記眩暈／打斷**（預設開）：標記該眩暈或打斷的讀條才用掉眩暈／打斷，近戰會用掃腿；模組要求保留時不把它們用在別的讀條
- **死刑前的短減傷**（預設開）：預告的死刑會打到你時，坦克循環先開一個冷卻短的減傷；大減傷照舊看血量門檻
- **依全體傷害危險度安排團減**（預設開）：危險度高才用大招與團盾，中只用冷卻短的，低就省下來
- **深層迷宮**：開打還沒進入戰鬥的敵人前先問會不會一次拉太多隻（預設開）；非首領層可設定只打斷被標記的詠唱（預設關）
- **手動技能佇列**：BossMod Reborn 接管手動技能佇列時，你手動按的技能不會被自動循環接著送的技能換掉

## 常用指令

| 指令 | 功能 |
|---|---|
| `/wrath`（舊別名 `/scombo`） | 開關主視窗 |
| `/wrath pve` / `pvp` / `settings` / `autosettings` | 開啟主視窗並跳至對應分頁 |
| `/wrath <職業縮寫>` | 開啟主視窗並跳至該職業的 PvE 分頁 |
| `/wrath auto` / `auto <on\|off\|toggle>` | 切換自動循環 |
| `/wrath stop` | 關閉自動循環，並收回其他插件對它的控制權 |
| `/wrath combo` / `combo <on\|off\|toggle>` | 切換動作替換（關閉時循環仍運作，但不替換技能） |
| `/wrath toggle\|set\|unset <名稱>` | 切換／開啟／關閉指定功能（戰鬥中無效）；`/wrath unsetall` 關閉全部 |
| `/wrath list set\|unset\|all [職業]` | 於聊天視窗列出功能狀態 |
| `/wrath ignore` | 把目前選取的敵人加入自動循環的忽略清單 |
| `/wrath debug [職業\|all]` | 匯出除錯檔到桌面，供回報問題用 |

完整指令與選項請見插件內或 `/wrath` 開啟的視窗。

## 台服版的修改

- 介面、技能名稱與說明繁體中文化（台服官方譯名，含新月島輔助職業）。
- 不再連到第三方伺服器取得 IPC 開關與登入公告。
- 赤魔道士新增 F.A.T.E. 接戰、全體傷害前自動昏亂／抗死、沒有治療職業時用赤療傷自補等選項。
- 赤魔道士自動復活新增三項規則（三項預設開，在自動循環的治療設定）：魔力只夠最後一發時只留給坦克與治療職業；小隊的坦克或治療職業全倒時中斷輸出先拉人；復活順序為治療職業、坦克、DPS。自動復活本身與「套用到召喚師、赤魔道士」預設關，要先開這兩項才會動；你自己選目標按復活不受這些規則限制。
- 自動復活不再選身上有「限制復活」狀態的隊友，被伺服器拒絕時不再對同一人連送；治療技能不再挑到剛倒地的隊友，「血量百分比最低」改成真的挑百分比最低的那一位。
- 自動循環與 BossMod Reborn、DailyDuty、MonsterDex 的整合（見上方「與其他插件整合」）；AoE 所需目標數可逐職業設定。
- 自動循環新增「提前排隊秒數」（預設 0.1 秒），下一招不必等 GCD 完全轉完才送。
- 新增 `/wrath stop`；PvP 新增三個全職業開關（見上方功能）。
- 機工士的跳彈射擊會掃到未交戰的敵人時不放，避免誤拉；多項技能可設定「目標 HP 在多少 % 以下就不放」。
- 多個插件（AutoDuty、BOCCHI 等）同時接管時，以最近更新的設定為準，停用或更新插件時會通知承租的插件。
- 遊戲改版後某個遊戲函式解不到時，插件照常載入，只停掉對應的那一項功能。
- 多處降低記憶體用量。

## 安裝

`/xlsettings` 開「Dalamud 設定」→「試驗性功能」→「第三方插件倉庫」，加入 `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json` 並啟用、儲存，再到「插件管理員」（`/xlplugins`）安裝；同一個插件只裝這裡的版本，不要同時裝上游版。
